# Orðusta MVP Product Plan, June 2026
Orðusta MVP is the final version of Orðusta that will be released for the public. It will include full functionality for excellent playability, authentication with Google and release deployment environment.

## Phase 1: Playability/function-completion in Icelandic for Playtest 2

Complete the playability improvements of the game. These are several, e.g.:

### Display opponent's moves immediately during a round

Display opponent's moves immediately during a round, i.e. not to wait for the round to complete for a player to see the opponent's moves. When the first players makes the move in a round, the second player will see the move.

Issue: https://linear.app/minni/issue/M-23

## Phase 2: Multi-language support

To be able to play the game in different languages, with different dictionaries. The game will be configurable to be deployed for different languages, with different word dictionaries. This will be configurable on the system level, but not required to be user-configurable, i.e. for the MVP release there will be different URLs/routes deployments for different languages.

Initial languages will be Icelandic, English, Norwegian, Danish and Swedish, in that order.

Also define the deployment environment for deploying the game for different languages, i.e. the game will have different deployment URLs for different languages, rather than it being a user-setting to switch language.

## Phase 3: Authentication and Onboarding

User authentication for global audience, with username only, i.e. the only info stored about players will be their username, but linked to their Google login.

## Phase 4: MVP quality cleanup and bugfixes and improvements before release

All outstanding quality review, bugfixes and cleanup before release. Feature and performance completion.

## Phase 5: Production Deployment Environment

The Production environment will be public and scalable, on Vercel and Supabase. This milestone will be about completing everything, for security, scalability and release process, so that the game can be for global audience.
